# Teddy Shi — Portfolio

A simple, responsive personal website using plain HTML and CSS. No framework, build step, or ChatGPT dependency.

## Edit

Edit `index.html` to replace the introduction, experience, research, projects, education, skills, side quests, and sidebar placeholders.

## Preview

Open `index.html` in your browser, or serve this folder locally:

```sh
python3 -m http.server 8000
```

## Host

This is a standard static website and can be hosted with GitHub Pages or any static web host. For GitHub Pages, choose the `main` branch and `/ (root)` under the repository’s **Settings → Pages**.
